1. Các giới hạn thực tế khi tích hợp krpano trên SkySOLIS và Đảo Kim Quy

Qua thực tế vận hành 5.460 files krpano trên dự án SkySOLIS và Đảo Kim Quy, việc nhúng một engine đóng cấu hình bằng XML như krpano vào ứng dụng Next.js / React bộc lộ 9 vấn đề kỹ thuật rõ rệt:

1. Bẫy hủy instance & rò rỉ vòng lặp WebGL

Hàm hủy của krpano là chữ thường window.removepano(id). Khi gọi nhầm removePano() hoặc khi React StrictMode chạy kép, instance cũ không bị hủy và tiếp tục bắn onviewchange làm lệch kim la bàn. Ở SkySOLIS phải thêm bộ đếm định danh krpanoEmbedSeq để xử lý.

KrpanoViewer.jsx (dòng 23, 176, 246)

2. Xung đột autorun="onstart" khi nạp cảnh

vtourskin.xml tự chạy cảnh đầu tiên trong file XML trước khi nhận được tham số startscene từ URL của React Router, gây tải lặp cảnh và làm sai lệch query parameter (phải dùng initialSceneLockRef để chặn).

src/app/amenities/[id]/client.jsx

3. Giới hạn truyền dữ liệu từ XML sang JS

Trình phân tích cú pháp js(...) trong XML của krpano tách tham số theo dấu phẩy mà không hiểu cú pháp Object { a: 1, b: 2 } của JavaScript, buộc phải đi vòng qua hàm toàn cục window.krpanoPostMessage.

Pano360Frame.jsx (dòng 26–37)

4. Phải polling 240 frames để dịch Hotspot

Ở SkySOLIS, các hotspot XML tạo layer chữ con bất đồng bộ sau khi tải xong ảnh. Khi người dùng đổi ngôn ngữ vi ↔ en, React phải chạy vòng lặp requestAnimationFrame kiểm tra liên tục suốt 240 frames (~4 giây) mới ghi đè được chữ dịch.

useKrpanoHotspotI18n.js (dòng 35–99)

5. Chi phí tính toán spheretoscreen 60fps

Ở Đảo Kim Quy, để vẽ hotspot bằng React component, hệ thống phải chạy vòng lặp 60fps gọi krpano.call("spheretoscreen(ath, atv, sx, sy)") trên từng điểm và dễ phát sinh xung đột z-index khi mở bảng thông tin dự án.

ReactHotspotsOverlay.jsx (dòng 50–85)

6. Mất hiệu ứng kính mờ backdrop-filter

Khi krpano thực hiện hiệu ứng chuyển cảnh OPENBLEND, trình duyệt mất lớp backdrop-filter: blur(10px) trên nhãn hotspot HTML, buộc phải viết action XML reapply_backdrop_blur dùng delayedcall để vẽ lại.

public/file360/plugins/flaghotspot.xml

7. Sự kiện onviewchange gây re-render liên tục

Krpano bắn góc quay dạng số thực ở mỗi khung hình. Nếu đẩy thẳng vào React state sẽ làm bản đồ Minimap và La bàn re-render 60 lần/giây (phải làm tròn Math.round(heading) và tách nội suy rAF riêng).

showroom/[type]/client.jsx & Compass360.jsx

8. Plugin FloorPlan gốc không thể tái sử dụng

Plugin bản đồ FloorPlan đi kèm krpano (dùng XML và jQuery cũ) không kết nối được với i18n và giao diện React của dự án, nên đều phải vô hiệu hóa và viết mới hoàn toàn bằng SVG React.

UtilityFloorPlan.jsx & HouseFloorPlan.jsx

9. Không thể mở đồng thời 2 KrpanoViewer

Do dùng chung id="krpanoContainer" và store đơn, ứng dụng không thể mở chồng 2 viewer trên cùng một trang DOM, khiến tính năng xem 360° Ban công từ trong Nhà mẫu phải nhúng qua thẻ <iframe>.

BanconyOverlay.jsx (dòng 45–62)

3. Ví dụ đối sánh cách triển khai Hotspot đa ngôn ngữ (next-intl) giữa 4 công nghệ

Chọn từng công nghệ bên dưới để so sánh mức độ gọn nhẹ khi gắn một điểm Hotspot có hỗ trợ đổi ngôn ngữ vi ↔ en và mở Modal React khi người dùng nhấn vào:

// 1. Khai báo cứng trong public/file360/overview/tour.xml:
// <hotspot name="hs_lobby" style="flag_icon" ath="42.5" atv="-8.2" text="Sảnh Đón"
//          onclick="js(window.krpanoPostMessage('open-utility', { id: 'lobby' }))" />

// 2. Trong src/hooks/useKrpanoHotspotI18n.js (Phải chạy vòng lặp chờ XML tạo xong layer chữ con):
useEffect(() => {
  let frame = 0;
  let rafId;
  const syncLabels = () => {
    const krpano = krpanoRef?.current;
    if (!krpano) {
      if (frame++ < 240) rafId = requestAnimationFrame(syncLabels);
      return;
    }
    let allApplied = true;
    for (const [hsName, i18nKey] of Object.entries(hotspotMap)) {
      const txtLayerName = `${hsName}txt`;
      if (!krpano.get(`layer[${txtLayerName}]`)) {
        allApplied = false;
        continue;
      }
      krpano.set(`layer[${txtLayerName}].html`, t(i18nKey));
    }
    if (!allApplied && frame++ < 240) rafId = requestAnimationFrame(syncLabels);
  };
  rafId = requestAnimationFrame(syncLabels);
  return () => cancelAnimationFrame(rafId);
}, [locale, activeScene]);
import { Viewer } from '@photo-sphere-viewer/core';
import { CubemapTilesAdapter } from '@photo-sphere-viewer/cubemap-tiles-adapter';
import { MarkersPlugin } from '@photo-sphere-viewer/markers-plugin';

const viewer = new Viewer({
  container: containerRef.current,
  adapter: CubemapTilesAdapter,
  panorama: {
    faceSize: 4096,
    nbTiles: 8,
    tileUrl: (face, col, row) => `/tiles/overview/${face}_${col}_${row}.webp`,
  },
  plugins: [[MarkersPlugin, { markers: [] }]],
});

// Khi đổi ngôn ngữ (vi <-> en), cập nhật trực tiếp DOM/HTML chuẩn mà không cần polling:
const markersPlugin = viewer.getPlugin(MarkersPlugin);
markersPlugin.setMarkers(
  hotspots.map((hs) => ({
    id: hs.id,
    position: { yaw: `${hs.ath}deg`, pitch: `${hs.atv}deg` },
    html: `<button class="hotspot-pill">${t(hs.i18nKey)}</button>`,
    data: { utilityId: hs.id },
  }))
);

markersPlugin.addEventListener('select-marker', ({ marker }) => {
  openUtilityModal(marker.data.utilityId);
});
import Marzipano from 'marzipano';
import { createPortal } from 'react-dom';

const geometry = new Marzipano.CubeGeometry([
  { tileSize: 512, size: 512 },
  { tileSize: 512, size: 2048 },
  { tileSize: 512, size: 4096 },

const view = new Marzipano.RectilinearView({ yaw: 0, pitch: 0, fov: Math.PI / 2 });
const scene = viewer.createScene({ source, geometry, view });

  yaw: (hs.ath * Math.PI) / 180,

return createPortal(
  <HotspotCallout title={t(hs.i18nKey)} onClick={() => openUtilityModal(hs.id)} />,
  domNode

import { Canvas } from '@react-three/fiber';

function PanoramaSphere({ textureUrl, hotspots, onSelect }) {
  const t = useTranslations('Overview');
  const texture = useTexture(textureUrl);

  return (
    <group>
      <mesh scale={[-1, 1, 1]}>
        <sphereGeometry args={[500, 64, 32]} />
        <meshBasicMaterial map={texture} side={2} />
      </mesh>

      {hotspots.map((hs) => (
        <Html key={hs.id} position={sphericalToCartesian(500, hs.ath, hs.atv)} center>
          <button onClick={() => onSelect(hs.id)} className="hotspot-pill">
            {t(hs.i18nKey)}
          </button>
        </Html>
      ))}
    </group>
  );
}

4. Kết luận và kế hoạch thử nghiệm trong thời gian tới

Kết luận chung: Mục tiêu của giai đoạn này không phải là thay thế krpano ngay lập tức trên các dự án đang chạy gấp, mà là nắm vững ưu/nhược điểm của từng công nghệ để có sẵn Plan B khi dự án yêu cầu tùy biến giao diện React sâu hơn hoặc kết hợp không gian 3D.

Định hướng sắp tới: Sẽ tiếp tục thực hiện thử nghiệm thực tế (Build POC) trong thời gian tới theo 3 bước cụ thể dưới đây.

Bước 1: Chuẩn hóa ngắn hạn

Tiếp tục sử dụng bản KrpanoViewer.jsx đã khắc phục lỗi hủy instance (removepano(id) + krpanoEmbedSeq) và khóa initialSceneLockRef của dự án SkySOLIS làm chuẩn chung cho các dự án hiện hành.

Bước 2: Thử nghiệm POC với Photo Sphere Viewer v5

Dựng bản POC thử nghiệm bằng Photo Sphere Viewer v5 (sử dụng CubemapTilesAdapter + MarkersPlugin) trên dữ liệu ảnh thực tế của dự án để đo đạc FPS, bộ nhớ Safari iOS và khả năng cập nhật đa ngôn ngữ tức thì.

Bước 3: Thử nghiệm POC liên thông 3D ↔ 360° với Three.js

Tận dụng bộ thư viện three + @react-three/fiber sẵn có trong dự án để thử nghiệm luồng trải nghiệm liên hoàn: Khám phá dự án → Tòa nhà 3D → Tầng → Căn hộ → Nội thất 360°.
