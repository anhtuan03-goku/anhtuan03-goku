Pain Point #1 • Vòng đời & Memory Leak
Bẫy hàm removepano(id) vs removePano() & Rò rỉ WebGL Loop
API hủy của krpano là chữ thường window.removepano(id). Ở bản cũ (Đảo Kim Quy), lệnh gọi window.removePano?.() âm thầm thất bại khiến instance cũ không bị hủy khi chuyển trang hoặc khi React 19 StrictMode mount kép, làm sự kiện onviewchange cũ tiếp tục bắn gây giật kim la bàn. Ở SkySOLIS, phải viết bộ đếm krpanoEmbedSeq UID để khắc phục.

Pain Point #6 • Lỗi Đồ họa Trình duyệt

So sánh độ phức tạp khi thực hiện cùng một yêu cầu thực tế tại Goku: "Hiển thị 1 điểm Hotspot tại tọa độ cầu (yaw/ath, pitch/atv) có hiệu ứng kính mờ backdrop-filter: blur(10px), tự động đổi ngôn ngữ vi ↔ en theo next-intl và mở Modal React khi click".

Hiện trạng trong SkySOLIS: Phải tách rời XML + Cầu nối window + Polling 240 frames Độ phức tạp cao • Dễ phát sinh race condition 
// 1. Trong public/file360/overview/tour.xml (Đóng cứng bằng ngôn ngữ XML riêng):
// <hotspot name="hs_lobby" style="flag_icon" ath="42.5" atv="-8.2" text="Sảnh Đón"
//          onclick="js(window.krpanoPostMessage('open-utility', { id: 'lobby' }))" />

// 2. Trong src/hooks/useKrpanoHotspotI18n.js (Phải chạy vòng lặp rAF chờ XML tạo xong layer con):
useEffect(() => {
  let frame = 0;
  let rafId;
  const syncLabels = () => {
    const krpano = krpanoRef?.current;
    if (!krpano) {
      if (frame++ < 240) rafId = requestAnimationFrame(syncLabels);
      return;
    }
    let allApplied = true;
    for (const [hsName, i18nKey] of Object.entries(hotspotMap)) {
      const txtLayerName = `${hsName}txt`;
      const layerExists = krpano.get(`layer[${txtLayerName}]`);
      if (!layerExists) {
        allApplied = false; // Ảnh hotspot chưa tải xong -> layer chữ chưa tồn tại!
        continue;
      }
      krpano.set(`layer[${txtLayerName}].html`, t(i18nKey));
    }
    if (!allApplied && frame++ < 240) {
      rafId = requestAnimationFrame(syncLabels); // Tiếp tục hỏi mỗi 16ms suốt 4 giây
    }
  };
  rafId = requestAnimationFrame(syncLabels);
  return () => cancelAnimationFrame(rafId);
}, [locale, activeScene]);

  { tileSize: 512, size: 512 },
  { tileSize: 512, size: 2048 },
  { tileSize: 512, size: 4096 },
]);
const source = Marzipano.ImageUrlSource.fromString('/tiles/{z}/{f}/{y}/{x}.webp');
const view = new Marzipano.RectilinearView({ yaw: 0, pitch: 0, fov: Math.PI / 2 });
const scene = viewer.createScene({ source, geometry, view });

// Gắn một thẻ div DOM chuẩn vào tọa độ (yaw, pitch) và dùng React Portal render vào trong:
const domNode = document.createElement('div');
scene.hotspotContainer().createHotspot(domNode, {
  yaw: (hs.ath * Math.PI) / 180,
  pitch: (hs.atv * Math.PI) / 180,
});

// Trong JSX: React tự động cập nhật i18n, state giỏ hàng và sự kiện onClick!
return createPortal(
  <HotspotCallout title={t(hs.i18nKey)} onClick={() => setSelectedId(hs.id)} />,
  domNode
);
