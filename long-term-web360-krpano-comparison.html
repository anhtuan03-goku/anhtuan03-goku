Nhằm giảm sự phụ thuộc vào một công nghệ duy nhất trong hệ thống Web360, báo cáo này tập trung nghiên cứu và đánh giá chuyên sâu 3 phương án công nghệ thay thế đã đề ra trong kế hoạch IDP: Photo Sphere Viewer, Marzipano và Three.js Custom Panorama Engine. Mục tiêu là nắm vững ưu/nhược điểm, đánh giá hiệu năng, tính khả thi và xây dựng Plan B về mặt công nghệ khi các sản phẩm trong tương lai cần mức độ tùy biến lớn hơn.

1. Photo Sphere Viewer (v5)
8.36 / 10
Thư viện mã nguồn mở (MIT) xây dựng trên nền Three.js, viết bằng TypeScript. Có sẵn hệ thống Plugin và Adapter đa phân giải hoàn chỉnh; tính khả thi triển khai nhanh cao nhất.
2. Marzipano (Google)
7.18 / 10
Engine WebGL 360° siêu nhẹ (~55KB gzipped, Apache 2.0). Tối ưu rất tốt cho Multi-resolution Tile Pyramid và gắn phần tử DOM, nhưng ít cập nhật mới và không hỗ trợ cảnh 3D.
3. Three.js Custom Panorama Engine
8.85 / 10
Xây dựng trực tiếp trên three + @react-three/fiber. Tự chủ 100% về Shaders, React UI và có khả năng liên thông trực tiếp với mô hình tòa nhà 3D.

1. Phân tích chuyên sâu 3 công nghệ được đưa vào nghiên cứu

Mỗi công nghệ dưới đây đại diện cho một hướng tiếp cận khác nhau khi xây dựng hệ thống tham quan ảo 360° trên nền tảng Web hiện đại (Next.js / React):

1. Photo Sphere Viewer (PSV v5)

Thư viện panorama mã nguồn mở hiện đại, được xây dựng trực tiếp bên trên Three.js với kiến trúc module hóa rõ ràng.

Cơ chế kỹ thuật nổi bật:

  • Hỗ trợ nhiều Adapter hiển thị: EquirectangularAdapter, CubemapAdapter, và đặc biệt là EquirectangularTilesAdapter / CubemapTilesAdapter cho ảnh đa phân giải 8K–16K.
  • Hệ thống Plugin chính thức phong phú: MarkersPlugin (hotspot HTML/SVG/Image), VirtualTourPlugin (chuyển cảnh giữa các node), MapPlugin & PlanPlugin (minimap/radar), GalleryPlugin, GyroscopePlugin.

Ưu điểm:

  • Viết hoàn toàn bằng TypeScript, có sẵn các sự kiện chuẩn JS và hàm dọn dẹp bộ nhớ viewer.destroy().
  • Thời gian tích hợp nhanh nhờ có sẵn đầy đủ tính năng của một tour 360° hoàn chỉnh.

Nhược điểm / Lưu ý:

  • Camera cố định tại tâm quả cầu panorama, chưa phù hợp nếu muốn bay camera tự do trong một mô hình kiến trúc 3D lớn bên ngoài.

2. Marzipano

Thư viện WebGL 360° độc lập do Google phát triển, tập trung tối đa vào tốc độ tải tile và sự gọn nhẹ.

Cơ chế kỹ thuật nổi bật:

  • Sử dụng WebGL thuần (không phụ thuộc Three.js), dung lượng chỉ khoảng ~55KB gzipped.
  • Quản lý hình học đa cấp độ (CubeGeometry, EquirectGeometry, FlatGeometry) với thuật toán tính toán vùng nhìn (frustum culling) và bộ đệm kết cấu GPU rất chặt chẽ.
  • Cung cấp hotspotContainer().createHotspot(domElement, { yaw, pitch }) tự động chiếu phần tử DOM 2D theo góc nhìn 3D.

Ưu điểm:

  • Hiệu năng hiển thị ảnh nhiều tầng phân giải (Multi-resolution tiles) rất mượt và tiết kiệm bộ nhớ trên thiết bị di động.
  • Gắn trực tiếp React Component vào hotspot thông qua createPortal rất tự nhiên.

Nhược điểm / Lưu ý:

  • Chỉ cung cấp nhân hiển thị cốt lõi; các tính năng như Minimap, Radar, Tour Node, Gallery hay hiệu ứng chuyển cảnh nâng cao đều phải tự viết thêm.
  • Kho mã nguồn chính thức ít được bổ sung tính năng mới trong những năm gần đây.

3. Three.js Custom Panorama Engine

Tự xây dựng engine panorama chuyên biệt trên nền three + @react-three/fiber + @react-three/drei.

Cơ chế kỹ thuật nổi bật:

  • Kết xuất quả cầu (SphereGeometry đảo mặt trong) hoặc khối lập phương (BoxGeometry) trực tiếp bên trong <Canvas> của React Three Fiber.
  • Hotspot được khai báo trực tiếp bằng <Html> component hoặc 3D Mesh trong cùng cây component của React, dùng chung trực tiếp với Zustand và next-intl.
  • Cho phép kết hợp mô hình 3D (.glb/.gltf) và quả cầu panorama 360° trong cùng một không gian WebGL.

Ưu điểm:

  • Khả năng tùy biến tuyệt đối: viết được Custom GLSL Shaders (hiệu ứng chuyển cảnh theo chiều sâu Depth Map, thanh trượt Ngày ↔ Đêm, hiệu ứng ánh sáng).
  • Đáp ứng trực tiếp mục tiêu dài hạn trong IDP: trải nghiệm xuyên suốt Dự án → Không gian → Tòa nhà → Tầng → Căn hộ → Nội thất.

Nhược điểm / Lưu ý:

  • Đòi hỏi thời gian R&D nhiều hơn để tự xây dựng bộ nạp Multi-resolution Tile Pyramid và quản lý giải phóng bộ nhớ GPU trên iOS Safari.

3. Ví dụ triển khai kỹ thuật của 3 phương án nghiên cứu

Chọn từng phương án bên dưới để xem cấu trúc code khi khởi tạo cảnh Panorama và gắn điểm Hotspot đa ngôn ngữ (next-intl) trong React:

import { Viewer } from '@photo-sphere-viewer/core';
import { CubemapTilesAdapter } from '@photo-sphere-viewer/cubemap-tiles-adapter';
import { MarkersPlugin } from '@photo-sphere-viewer/markers-plugin';

// Khởi tạo Viewer với Multi-resolution Cubemap Tiles
const viewer = new Viewer({
  container: containerRef.current,
  adapter: CubemapTilesAdapter,
  panorama: {
    faceSize: 4096,
    nbTiles: 8,
    tileUrl: (face, col, row) => `/tiles/overview/${face}_${col}_${row}.webp`,
  },
  plugins: [[MarkersPlugin, { markers: [] }]],
});

// Cập nhật danh sách Hotspot theo ngôn ngữ hiện tại (vi / en):
const markersPlugin = viewer.getPlugin(MarkersPlugin);
markersPlugin.setMarkers(
  hotspots.map((hs) => ({
    id: hs.id,
    position: { yaw: `${hs.ath}deg`, pitch: `${hs.atv}deg` },
    html: `<button class="hotspot-pill">${t(hs.i18nKey)}</button>`,
    data: { utilityId: hs.id },
  }))
);

markersPlugin.addEventListener('select-marker', ({ marker }) => {
  openUtilityModal(marker.data.utilityId);
});
import Marzipano from 'marzipano';
import { createPortal } from 'react-dom';

// Khởi tạo hình học Multi-resolution Cube Pyramid
const geometry = new Marzipano.CubeGeometry([
  { tileSize: 512, size: 512 },
  { tileSize: 512, size: 2048 },
  { tileSize: 512, size: 4096 },
]);
const source = Marzipano.ImageUrlSource.fromString('/tiles/{z}/{f}/{y}/{x}.webp');
const view = new Marzipano.RectilinearView({ yaw: 0, pitch: 0, fov: Math.PI / 2 });
const scene = viewer.createScene({ source, geometry, view });

// Gắn phần tử DOM trực tiếp vào tọa độ cầu và kết xuất React Component qua Portal:
const domNode = document.createElement('div');
scene.hotspotContainer().createHotspot(domNode, {
  yaw: (hs.ath * Math.PI) / 180,
  pitch: (hs.atv * Math.PI) / 180,
});

return createPortal(
  <HotspotCallout title={t(hs.i18nKey)} onClick={() => openUtilityModal(hs.id)} />,
  domNode
);
import { Canvas } from '@react-three/fiber';
import { Html, OrbitControls, useTexture } from '@react-three/drei';
import { useTranslations } from 'next-intl';

function PanoramaSphere({ textureUrl, hotspots, onSelect }) {
  const t = useTranslations('Overview');
  const texture = useTexture(textureUrl);

  return (
    <group>
      <mesh scale={[-1, 1, 1]}>
        <sphereGeometry args={[500, 64, 32]} />
        <meshBasicMaterial map={texture} side={2} />
      </mesh>

      {hotspots.map((hs) => (
        <Html key={hs.id} position={sphericalToCartesian(500, hs.ath, hs.atv)} center>
          <button onClick={() => onSelect(hs.id)} className="hotspot-pill">
            {t(hs.i18nKey)}
          </button>
        </Html>
      ))}
    </group>
  );
}

4. Kết luận và định hướng tiếp tục thử nghiệm trong thời gian tới

Kết luận đánh giá: Cả 3 công nghệ được đưa ra đều giải quyết tốt bài toán làm chủ mã nguồn bằng JavaScript/TypeScript và tích hợp trực tiếp với giao diện React. Trong đó, Photo Sphere Viewer v5 (8.36/10) nổi bật về tính sẵn sàng để triển khai nhanh nhờ hệ sinh thái plugin hoàn chỉnh, còn Three.js Custom Panorama Engine (8.85/10) mang lại khả năng mở rộng lớn nhất cho định hướng kết hợp Web 3D và Web360.

Định hướng hành động: Sẽ tiếp tục thực hiện thử nghiệm thực tế (Build POC) trong thời gian tới để đo đạc số liệu vận hành trực tiếp trên tài sản dữ liệu của dự án.

Bước 1: Thử nghiệm POC với Photo Sphere Viewer v5

Dựng bản thử nghiệm sử dụng CubemapTilesAdapter, VirtualTourPlugin và MarkersPlugin để đánh giá tốc độ tải lưới ảnh đa phân giải, mức tiêu thụ bộ nhớ trên thiết bị di động và khả năng tùy biến giao diện Hotspot.

Bước 2: Nghiên cứu thuật toán Tile Loading từ Marzipano

Tham khảo cách tổ chức cấu trúc tháp ảnh (tile pyramid) và cơ chế tính toán vùng nhìn (frustum culling) của Marzipano để áp dụng vào việc tối ưu hóa bộ nạp ảnh đa cấp.

Bước 3: Xây dựng POC liên thông 3D ↔ 360° với Three.js

Tận dụng bộ thư viện three + @react-three/fiber sẵn có trong Base Template để thử nghiệm trải nghiệm xuyên suốt: Khám phá dự án → Không gian → Tòa nhà → Tầng → Căn hộ → Nội thất.
